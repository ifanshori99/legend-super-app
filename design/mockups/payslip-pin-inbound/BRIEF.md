# #425 — Rencana mockup inbound WhatsApp

Brief utama: `docs/briefs/425-designer-lupa-pin-inbound.md` di repo utama. Keluaran hanya folder ini; jangan ubah aplikasi. Basis cabang `origin/milestone/m1` 46352cd5. Arah visual sudah ditetapkan: tiru layar yang dibangun di `.worktrees/payslip-pin-ui/design/screenshots/payslip-pin/`, khususnya `lupa-pin-390.png`, `buat-pin-390.png`, dan `kode-whatsapp-390.png`. Tidak membuat arah visual baru atau desktop.

## Alur dan batas

Pilih WhatsApp → tantangan tampil → buka WhatsApp dengan pesan sudah terisi → karyawan menekan Kirim sendiri, memakai nomor terdaftar → kembali ke web yang sama → web mengecek penerimaan → popup sukses → buat PIN baru. Tidak ada input OTP dari WhatsApp, tidak ada balasan WhatsApp, membuka WhatsApp saja bukan bukti berhasil. HR/supervisor adalah jalur manual, tidak berpura-pura mengirim permintaan.

## Visual

390px lebar. White #fff; ink #1c1b19; muted #69645e; border #e8e5e1; teal #0f5e68; warm box #f5f4f2. Font Plus Jakarta Sans lokal dari referensi. Header Cafe Legend + monitor icon, back Slip gaji, eyebrow PRIVASI GAJI, judul Slip gaji, subtitle seperti screenshot. Kartu x16 w358 p20 r12; judul21px; body16px/22px; pill CTA56px. Bottom nav Karyawan/Absen/Riwayat/Slip Gaji/Lainnya seperti screenshot. Ikon outline, tidak ada ilustrasi dekoratif. Layar panjang boleh 390×1000–1100 supaya teks tetap16px; tinggi lainnya844. Jangan kecilkan teks untuk memaksa muat.

## Data contoh, bukan kebijakan baru

Nomor terdaftar `+62 812-••••-4821`; nomor tujuan ilustrasi `+62 812-0000-4250` (belum ada nomor layanan nyata, tidak boleh membuat tautan wa.me aktif ke nomor contoh). Pesan contoh `PIN K7M9-2Q4P`, bukan PIN pribadi. Format final dari kontrak #424. TTL contoh 5 menit mengikuti lama, timer snapshot04:59. Rate limit snapshot09:59 dari retry-after server, tidak menetapkan kuota/masa tunggu baru. Tulis perbedaan data contoh dan konfigurasi final pada README.

## Pemeriksaan

Tiap PNG tepat390px; semua copy tampak, tidak terpotong. Bandingkan layar satu per satu. Periksa kontras teks/CTA dan target sentuh, font lokal berhasil dimuat, kode teks bukan input OTP, tidak ada WA reply atau sukses palsu. Mockup statis, bukan integrasi backend. Render via heavy bila Playwright. Reviewer segar memeriksa alur serta PNG sebelum commit/push. Semua sumber desain deterministik dan font boleh berada di folder ini untuk regenerasi.
