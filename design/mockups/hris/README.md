# Mockup HRIS

Contoh data, nama, tanggal dan saldo pada gambar bersifat ilustratif. Formulir karyawan pada lebar 390 px mencakup tukar shift, ganti shift, cuti/izin dan lembur. Gambar antrean dan detail supervisor tersedia pada lebar 1280 px dan 390 px.

Kondisi yang digambarkan: kosong, pengajuan/keputusan berhasil, penolakan dan offline. Saat offline, pengajuan atau keputusan belum terkirim; pengguna mencoba lagi setelah tersambung. Tukar shift menampilkan penerimaan rekan sebelum tinjauan supervisor dan peringatan aturan jam kerja.

Sumber: `hris.html`; untuk merender semua gambar, jalankan `heavy node design/mockups/hris/render.mjs` dari akar repo setelah dependensi terpasang. Mockup statis ini bukan implementasi interaksi atau bukti audit aksesibilitas.
