## Antarmuka hook (A dan B menulis ini persis; C-F memakai)

HRIS `@/features/hris-requests/hooks`:

- `useMyShiftSwaps()`, `useMyLeaveRequests()`, `useMyOvertimeRequests()` → query list (DTO kontrak).
- `useLeaveBalances()`, `useLeaveTypes()`, `useMyShiftAssignments()` (shift saya ke depan), `useSwapCandidates(fromAssignmentId)` (rekan + shift rekan; dari data yang ada), `useHolidays({ from, to })`.
- `useCreateShiftSwap()`, `useCreateLeaveRequest()`, `useCreateOvertimeRequest()`, `useCancelShiftSwap()` → mutation; idempotencyKey dibuat di hook.
- `useRequestQueue({ status? })` → `RequestQueueItem[]` dari `queue.ts`: `{ kind: "swap"|"cover"|"leave"|"overtime", id, employeeId, employeeName, title, period, submittedAt, status, complianceIssues?, raw }`.
- `useRequestDetail(kind, id)` → `RequestQueueItem | undefined`.
- `useDecideRequest()` → mutate `{ kind, id, decision: "approve"|"reject", reason?: string }` (swap dengan complianceIssues: approve = `approve_with_override` + reason wajib).
  Akses dukungan `@/features/ws01-support-access/hooks`:
- `useSupportAccessRequests()` → query list `SupportAccessRequest[]`.
- `useApproveSupportAccessRequest()`, `useRejectSupportAccessRequest()` → mutate `{ requestId }`.
- Cabut grant aktif: pakai hook cabut/akhiri grant yang SUDAH ada di `hooks.ts` (B pastikan diekspor dan sebut namanya di laporan).
- `useSupportDecisionGuard()` → `{ canDecide: boolean, reason: "impersonating"|"mfa_required"|"not_owner"|null }` dari sesi/area access (`lib/areas/access.ts`, `session.impersonatedBy`).
