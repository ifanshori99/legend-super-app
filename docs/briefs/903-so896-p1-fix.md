Harus: event tetap bisa di-retry, intent tetap terpilih poll (`payment-live-code.ts` ~:47), `provider_final_at` NULL.
- Test baru `apps/api/src/test/qris-hold-so896-p1-zero-paid.test.ts` (pola: `qris-hold-so896-p2-parking.test.ts`, `qris-hold-so896-poll-failed.test.ts`):

Lalu status pulih paid penuh tanpa webhook baru -> poll/retry berulang mencatat atau memarkir uang tepat sekali (cek evidence satu baris, dana satu baris, event satu).
  2. Intent `failed` nonfinal di jalur poll (`payment.service.ts` ~:2777): paid nominal 0 -> final tetap NULL; pulih paid penuh -> uang diparkir tepat sekali.
