## Card A DESIGN DECISION v2 (supersedes "fill only where NULL")
stock.moved rows (one per ingredient) arrive AFTER order.paid and possibly in separate batches, and nothing says "all rows arrived". So cost_snapshot_idr is a CONVERGENT RECOMPUTE, an assignment not an increment: after each order-sourced stock.moved applied (movementType='sale', sourceId = order id) and after order.paid is parked, set the parked order.paid row's cost_snapshot_idr = SUM(|qty| x unitCost) over ledger rows (tenant, outlet, sourceId), rounded once with scaledCostToIdr. Replays/any arrival order converge to the same value and never double. The column is written ONLY by this recompute (new column), so overwriting is safe; this replaces the "never overwrite" rule from brief 277 for this column only. No row yet -> stays NULL.
